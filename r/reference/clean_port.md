# Validate a parallel-port address, which is written into the script unquoted

Validate a parallel-port address, which is written into the script
unquoted

## Usage

``` r
clean_port(value, field = "triggers.parallel_address")
```

## Arguments

- value:

  A value coerced to a single string.

- field:

  Field name, for error messages.

## Value

The value as a plain string.
