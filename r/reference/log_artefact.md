# Record a written artefact (path, rows, fingerprint) in the log

Record a written artefact (path, rows, fingerprint) in the log

## Usage

``` r
log_artefact(log, path, rows = NA_integer_)
```

## Arguments

- log:

  A run-log object.

- path:

  A file path that has just been written.

- rows:

  Optional row count.

## Value

The updated run-log object.
