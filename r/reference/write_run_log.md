# Write the run log to Markdown (and optionally JSON Lines)

Write the run log to Markdown (and optionally JSON Lines)

## Usage

``` r
write_run_log(log, md_path, jsonl_path = NULL)
```

## Arguments

- log:

  A run-log object.

- md_path:

  Output path for the Markdown log.

- jsonl_path:

  Optional output path for the JSON Lines log.

## Value

`md_path`, invisibly.
